To-Do List Webpage

Technologies Used: HTML5, CSS3, JavaScript

Developed an interactive To-Do List webpage using HTML, CSS, and JavaScript to help users manage their daily tasks efficiently.

Key Features:

Add Tasks: Easily add new tasks to the list.
Delete Tasks: Remove completed or unnecessary tasks.
Mark as Completed: Mark tasks as completed with a single click.
User-Friendly Interface: Designed a clean and attractive layout using CSS.
Interactive Functionality: Used JavaScript to manage tasks dynamically.

Learning Outcomes: Improved my knowledge of JavaScript, DOM manipulation, 
event handling, and front-end web development. Gained practical experience in creating interactive and user-friendly web applications.
